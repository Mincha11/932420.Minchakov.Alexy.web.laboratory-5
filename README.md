Работа с DOM
Для поиска элементов используются:
- getElementById()
- querySelector()
- querySelectorAll()

С помощью JavaScript изменяется текст заголовка,
добавляются и удаляются карточки игр, а также изменяются
CSS-классы элементов.

Список любимых игр
На странице реализован список любимых игр с рейтингом.
Каждая карточка содержит:
- название игры;
- жанр;
- рейтинг от 1 до 5;
- звёздное отображение рейтинга;
- кнопку удаления.
Кнопка «Добавить игру» запрашивает название, жанр и рейтинг
через prompt().
Кнопка «Удалить последнюю» удаляет последнюю игру из списка.
У каждой карточки также имеется собственная кнопка «Удалить».
 Переключение темы
Кнопка позволяет переключаться между светлой и тёмной темами.
Выбранная тема сохраняется в localStorage.
 Скрытие и показ списка
Реализована кнопка для скрытия и показа списка любимых игр.
Состояние видимости сохраняется после перезагрузки страницы.
 Обработка ошибок
Программа проверяет:
- существование HTML-элементов;
- заполненность названия и жанра игры;
- корректность рейтинга;
- наличие игр перед удалением;
- возможность чтения и записи данных в localStorage.
Сохранение данных
В localStorage сохраняются:
- список любимых игр;
- выбранная тема оформления;
- состояние видимости списка;
- состояние заголовка страницы.
После перезагрузки страницы сохранённые данные
восстанавливаются автоматически.
